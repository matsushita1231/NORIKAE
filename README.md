# でんしゃマップ（NORIKAE）

京急本線（京急川崎〜横浜）と JR 鶴見線の列車を、デフォルメした路線図の上で動かして見るための Web アプリです。
スライダーで最大 120 分先までの列車位置を予想し、浅野〜子安の乗り継ぎ（鶴見経由／国道経由）と待ち時間を比べられます。

## 使い方

1. GitHub Pages で公開された URL を iPhone の Safari で開き、「ホーム画面に追加」します。
2. 右上の ⚙︎ から、公共交通オープンデータセンターの「チャレンジ2026」用アクセストークンを入力します。
   トークンはその端末のブラウザ内（localStorage）にだけ保存され、このリポジトリには含まれません。
3. トークン未設定のときは、動作確認用のデモダイヤで動きます。

## データについて

- 京急：列車ロケーション情報、駅時刻表（駅時刻表をつなぎ合わせて列車ごとのダイヤを復元し、位置から遅れを推定）
- JR 鶴見線：列車時刻表（リアルタイム位置の提供がないため、時刻表から位置を推定）

本アプリケーションが利用する公共交通データは、[公共交通オープンデータセンター](https://www.odpt.org/)において提供されるものです。
公共交通事業者により提供されたデータを元にしていますが、必ずしも正確・完全なものとは限りません。
本アプリケーションの表示内容について、公共交通事業者への直接の問合せは行わないでください。
本アプリケーションに関するお問い合わせは、このリポジトリの Issues にお願いします。

データの利用条件は「公共交通オープンデータチャレンジ限定ライセンス」および各データセットの特定利用条件
（https://developer.odpt.org/terms ）に従います。チャレンジ限定データは、チャレンジの期間終了後は利用できなくなる場合があります。

## 構成

ビルド不要の静的サイトです。

- `index.html` / `style.css`：画面
- `js/network.js`：路線・駅のデフォルメ配置
- `js/timetable.js`：ダイヤから列車位置・発車時刻を求める処理、デモダイヤ
- `js/odpt.js`：ODPT API からの取得、京急ダイヤの復元、遅れの推定
- `js/app.js`：描画、未来スライダー、乗り継ぎ比較、LINE 共有
- `sw.js` / `manifest.webmanifest`：ホーム画面アプリ（PWA）用
